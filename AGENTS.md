# AUREL — Knowledge Distillation Project

## Project Overview

Build a professional AI research application that demonstrates Knowledge Distillation using CIFAR-10.

## Models

The project contains three models:

1. Teacher Model — ResNet-18
2. Baseline Student Model — Custom CNN
3. Distilled Student Model — Custom CNN

Always inspect the original training notebooks to verify the exact architectures and configurations.

## Important Rules

- Never modify or delete original notebooks or trained checkpoints.
- Never retrain models unless explicitly instructed.
- Never invent accuracy, loss, latency, or other experimental results.
- Clearly distinguish validation metrics from test metrics.
- Do not assume model architectures or preprocessing.
- Do not silently ignore checkpoint-loading errors.
- Keep the code modular and readable.
- Support CPU inference and use GPU when available.
- Do not use randomly initialized models as a fallback.

## Design Direction

Create a sophisticated, spacious, professional AI research interface.

Use:

- Dark graphite and warm off-white.
- Muted sage, teal and blue accents.
- Large typography and generous spacing.
- Wide charts and clear visualizations.
- Clean layouts with strong visual hierarchy.

Avoid:

- Generic dashboard templates.
- Compact layouts.
- Excessive cards and rounded boxes.
- Neon colors and excessive gradients.
- Tiny text and unnecessary animations.
